# NEXCRAFT Launcher

**NEXCRAFT Launcher** is an Android launcher for Minecraft: Java Edition. It is maintained in this repository:

- Project: https://github.com/maxtroitofficial/NEXCRAFT
- Official creator channel: https://www.youtube.com/@maxtroit_official

## Build

- Android Studio
- Android SDK (minimum API 26; target API 35)
- JDK 11

Open this repository in Android Studio and build the Android app module.
