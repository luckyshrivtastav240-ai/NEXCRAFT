# NEXCRAFT Launcher

**NEXCRAFT Launcher** 是一款面向 Android 裝置的 Minecraft: Java Edition 啟動器。本專案由 NEXCRAFT 維護：

- 專案：https://github.com/maxtroitofficial/NEXCRAFT
- 官方創作者 YouTube 頻道：https://www.youtube.com/@maxtroit_official

## 建置方式

- Android Studio
- Android SDK（最低 API 26；目標 API 35）
- JDK 11

使用 Android Studio 開啟此儲存庫並建置 Android App 模組。
